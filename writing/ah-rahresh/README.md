## Política de canon

1. Texto-fonte e decisões explícitas do autor têm prioridade sobre inferências.
2. Documentos canônicos mais recentes têm prioridade sobre lembranças antigas quando há conflito.
3. Variantes antigas relevantes são preservadas como histórico, não apagadas.
4. Material recuperado de conversa não deve ser promovido automaticamente a canon quando estiver marcado como incerto, provisório ou supersedido.
5. `Adormecer do Fogo` é tratado como obra fechada; material de preservação não implica autorização para reescrevê-lo.

## Fontes binárias

Foram localizados na Library do ChatGPT PDFs dos romances, um DOCX de fundação e a ficha PNG de Nadir. Seus hashes e duplicatas estão registrados no manifesto. Os binários que a conexão GitHub desta sessão não conseguiu receber diretamente permanecem explicitamente marcados como **não anexados**, para que o inventário não confunda “localizado” com “gravado no repositório”.
