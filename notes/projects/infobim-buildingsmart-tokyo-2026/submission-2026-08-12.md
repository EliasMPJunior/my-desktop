- **Presentation title:** **Distributed Semantic Mesh for Executable OpenBIM: Linking Project Information with IFC and ISO 21597**

## Abstract / Overview

Traditional CDE implementations commonly concentrate project information, metadata, relationships, and workflows within repository-centric platforms, making portions of the project context dependent on the hosting environment.

This presentation proposes an alternative architectural paradigm: a distributed, local-first semantic mesh that separates the physical storage of data from its logical meaning. Aligned with the information-management principles of ISO 19650 and the technical specifications of ISO 21597 (Information Containers for Linked Document Delivery - ICDD), this approach allows heterogeneous project assets—such as Industry Foundation Classes (IFC) models, PDFs, spreadsheets, and communications—to remain intact in their native formats and existing information environments.

We will explore how this architecture enables "Data with Brains," a framework where open, machine-readable relationship structures computationally describe the meaning, dependencies, and applicable technical operations of engineering data, enabling OpenBIM information to participate in deterministic, executable workflows. To bridge theory and practice, the session will feature a live demonstration of this tool-independent architecture using InfoBIM, an open-source Apache 2.0-licensed implementation developed in Brazil, illustrating how an ordinary project directory is transformed into a traceable, semantically linked WorkStream without file migration or day-to-day workflow disruption.

## Objectives

1. To compare the architectural characteristics and trade-offs of repository-centric CDEs and distributed, local-first semantic meshes.
2. To demonstrate how ISO 21597 (ICDD) linksets can drive explicit relationships across heterogeneous project resources.
3. To define the technical requirements for making OpenBIM metadata machine-readable and executable locally and offline.

## Learning Outcomes

- Structure and deploy explicit, external linksets to connect elements within IFC models to raw documents.
